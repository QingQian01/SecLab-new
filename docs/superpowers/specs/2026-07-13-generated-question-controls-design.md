# AI 生成题列表状态与操作控件改造设计

## 目标

修复教师端 AI 生成题列表中“审核状态”和“查看”控件因表格列宽不足而发生中文换行、外形变形的问题，同时提升状态辨识度。现有展开与收起行为保持不变。

## 范围

- 仅修改 `SecLab-FrontEnd-2/src/pages/Admin/GeneratedQuestions/index.vue`。
- 不调整表格字段、接口调用、数据结构、路由或展开内容。
- 不涉及数据库、事件类型、日志埋点和错误处理。

## 视觉设计

### 审核状态

- 将统一的描边徽标改为单行语义色胶囊。
- `PENDING_REVIEW`：琥珀色，文案“待审核”。
- `APPROVED`：绿色，文案“已通过”。
- `REJECTED`：红色，文案“未通过”。
- `NEEDS_REVISION`：橙色，文案“需修改”。
- 未识别状态沿用“待审核”视觉。
- 胶囊使用固定单行、适度水平留白和轻边框，避免文字纵向断行。

### 查看操作

- 将高饱和度实心小按钮改为白底蓝色描边的轻量按钮。
- “查看”状态显示眼睛图标；展开后显示向上箭头和“收起”。
- 按钮使用固定高度、最小宽度和禁止换行，保证两字文案不变形。
- 点击区域、展开状态和原有行详情逻辑不变。

## 实现边界

- 增加一个审核状态样式映射函数，集中管理状态与 Tailwind/DaisyUI 类名。
- 使用项目已安装的 `@heroicons/vue`，不引入新依赖。
- 保留当前页面中尚未提交的请求竞态保护及其他改动，不覆盖、不重写。

## 验证

- 运行 `npm run vue-tsc`。
- 运行 `npm run build`。
- 启动页面后检查桌面宽度下四种状态均为单行胶囊。
- 点击“查看”和“收起”，确认详情行正常展开和关闭，按钮无换行、无裁切。
- 检查页面无 Vite 错误覆盖层及相关控制台错误。
