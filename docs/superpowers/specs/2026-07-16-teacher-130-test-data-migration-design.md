# 教师端 130 人测试数据安全迁移设计

## 背景与目标

外部压缩包 `数据库文件.rar` 提供了教师端教学班结构和 130 名学生的测试数据。测试数据需要直接导入当前本机的 `userservice` 与 `seclab_profile` 数据库，使现有系统页面和接口能够立即使用，同时还要作为仓库内可复现的数据集提供给其他协作者。

当前数据库已经包含 64 个用户、12 门课程、1 个教学班，以及学号段 `202321040501` 至 `202321040630` 中的 32 个测试账号。这 32 个账号还关联 32 条训练记录、40 条答题记录和 64 条学习事件。原始 130 人脚本会删除这些账号，但不会删除所有既有历史记录，直接执行会产生孤立数据。脚本依赖的教师账号 `T20260001` 当前也不存在。

本迁移采用安全增量方式：保留当前数据和主键，补齐并更新测试数据，不执行压缩包中的全量重置脚本。

## 范围

迁移包含：

- 将教学班结构与 130 人测试数据整理成仓库内可复现的 SQL。
- 在当前数据库中创建或补齐测试教师、130 名学生、教学班、班级成员与课程关系。
- 导入训练、题目、答题、学习事件和教师分析数据。
- 提供导入前检查、备份、迁移后验证和恢复说明。
- 提交并推送脚本和文档，使其他协作者能够在自己的数据库中复现。

迁移不包含：

- 执行 `reset_and_seed_teacher_demo.sql` 或 `seed_teacher_showcase.sql`。
- 删除现有非本数据集的数据。
- 修改应用业务逻辑或数据库连接目标。
- 将本机数据库二进制文件或包含凭据的配置提交到仓库。

## 方案选择

采用“同库安全 Upsert”方案。相比修改学号后并行导入，该方案保持压缩包测试数据的原始身份；相比删除后重建，该方案保留现有用户主键和历史关联。

测试数据由两个稳定边界标识：

- 学生账号：学号段 `202321040501` 至 `202321040630`。
- 行为与分析数据：标识前缀 `teacher-demo-20260716-`。

导入可以重复执行。重复执行时，只刷新本数据集自身带前缀的行为与分析记录；已有学生账号使用学号匹配并更新允许变化的展示字段，不删除账号，不更换 `user_id`。

## 数据流

1. 执行只读预检，确认 MySQL 版本、目标库、基础表、测试教师、管理班级和课程 1 至 8 的状态。
2. 使用 `mysqldump` 分别备份 `userservice` 和 `seclab_profile`，记录备份文件路径和校验值。
3. 应用无破坏性的教师教学班结构脚本，补齐缺失表、字段、索引和约束。
4. 创建缺失的测试教师；若账号已经存在，则保留其主键和密码，仅补齐教师角色等必要字段。
5. 按学号 Upsert 130 名学生。已有 32 名学生保留 `user_id`，其余学生新增。
6. Upsert 指定教学班，并建立 130 条教学班成员关系及 8 条课程关系。
7. 删除并重建仅属于 `teacher-demo-20260716-*` 前缀的数据，然后写入训练、题目、答题、学习事件和教师分析数据。
8. 执行数据库验证及教师端接口回归检查。
9. 提交并推送安全迁移脚本、验证脚本和使用说明；备份文件不进入 Git。

## 数据保护与事务边界

- 导入前必须成功生成两个数据库的备份；任一备份失败都停止迁移。
- 原脚本中删除整个学号段用户的语句必须移除。
- 清理操作必须同时满足目标表和 `teacher-demo-20260716-*` 前缀条件。
- 学生 Upsert 不能更新 `user_id`，以保护现有训练和学习事件的关联。
- 教学班成员与课程关系采用唯一键 Upsert，不先清空现有关系。
- DDL 与数据导入分阶段执行。数据导入阶段使用事务，并在任何 SQL 错误时回滚。
- SQL 和命令输出不得记录数据库密码；仓库只保存环境变量示例。

## 异常处理与恢复

预检发现以下任一情况时停止并报告，不自动猜测：

- 目标库或基础表不存在。
- 课程 1 至 8 缺失。
- 同一学号对应多个账号，或测试教师账号存在身份冲突。
- 现有表结构与迁移要求不兼容。

数据阶段失败时先回滚事务，再检查前缀数据和账号数量是否保持迁移前状态。若 DDL 阶段或事务外操作导致状态无法自动恢复，则停止服务，并使用导入前备份恢复两个数据库。

## 验证标准

数据库迁移成功必须同时满足：

- 学号段内恰好有 130 个唯一学生账号。
- 测试教师存在且角色为教师。
- 指定教学班恰好关联 130 名学生和 8 门课程。
- 当前已有 32 个学生的 `user_id` 在迁移前后不变。
- 所有 `teacher-demo-20260716-*` 训练、题目、答题和学习事件均能关联到有效用户。
- 教学班、学生、课程和教师分析相关检查的孤立记录数均为 0。
- 第二次执行迁移后，受管数据行数不增长，证明导入具有幂等性。
- 教师端登录、教学班列表、班级分析和学生分析接口通过回归检查。

## 仓库交付物

实施阶段将新增或更新以下内容：

- 安全版 130 人测试数据 SQL。
- 导入前预检与迁移后验证脚本。
- 数据库迁移运行说明，包含备份、导入、验证和恢复命令。
- 必要的 SQL 静态回归测试，阻止无条件 `DELETE`、`DROP` 或 `TRUNCATE` 混入测试数据脚本。

数据库备份、运行日志、真实凭据和 MySQL 数据目录均不提交到仓库。
