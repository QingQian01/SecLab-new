# 教师端实验分析文案精简设计

## 目标

让教师直接看到本实验的答题结果、待回看的知识点、错题数和涉及学生，删除面向系统实现的解释和模板化教学口号。

## 页面表达

- 标题使用“班级实验分析”。
- 操作按钮使用“更新分析”，加载时显示“更新中…”。
- 总览只陈述题目数、作答数和正确率，不使用“重点关注”等总结腔。
- 知识点卡片只显示知识点名称、正确率、仍答错题目数和涉及学生数。
- 删除“教学动作”灰色说明条。
- 删除底部“建议下一步”及跨课程画像说明。
- 无结果时显示“暂无分析结果”。

## 数据与交互

不改变分析接口、统计口径和数据字段。教师需要查看学生答案、错题详情或布置练习时，继续使用页面已有的知识点详情入口。

## 验证

- 组件测试检查旧文案不再出现、核心统计字段仍被渲染。
- 后端测试检查兜底分析不再生成模板化教学建议。
- 浏览器验证班级实验分析页面能正常显示，且无旧文案和控制台错误。
